# Recruitment Funnel & Hiring Analytics | Power BI

## 📌 Project Overview

This project focuses on analyzing the recruitment and hiring process using **Microsoft Power BI**.

The dashboard tracks candidates through different recruitment stages — from application and screening to interviews, offers, and joining. It helps understand the recruitment funnel, conversion rates, hiring progress, and time-to-hire.

The project was created as a practical **HR Analytics / Recruitment Analytics** project to demonstrate how HR data can be cleaned, analyzed, and transformed into an interactive dashboard for recruitment decision-making.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze the complete recruitment funnel.
* Track candidates across different hiring stages.
* Measure stage-wise conversion rates.
* Monitor recruitment KPIs.
* Analyze candidate sources and job roles.
* Understand recruitment performance across departments and locations.
* Track offer-to-joining conversion.
* Analyze time-to-hire.
* Build an interactive HR recruitment dashboard using Power BI.

## 📊 Dataset

The recruitment dataset contains candidate-level information used to analyze the hiring funnel.

### Key Columns

| Column           | Description                           |
| ---------------- | ------------------------------------- |
| Candidate_ID     | Unique candidate identifier           |
| Application_Date | Date when the candidate applied       |
| Department       | Department associated with the job    |
| Job_Role         | Position applied for                  |
| Source           | Candidate sourcing channel            |
| Location         | Candidate/job location                |
| Gender           | Candidate gender                      |
| Education        | Candidate education level             |
| Experience_Years | Years of prior experience             |
| Screened         | Screening status                      |
| Interviewed      | Interview status                      |
| Offered          | Offer status                          |
| Joined           | Joining status                        |
| Current Stage    | Current stage of the candidate        |
| Stage Order      | Numerical order of recruitment stages |
| Time to Hire     | Time taken during the hiring process  |

---

## 🔄 Recruitment Funnel

The recruitment process analyzed in this project follows these stages:

**Applied → Screened → Interviewed → Offered → Joined**

The dashboard allows users to understand how candidates move through the recruitment pipeline and where candidate drop-offs occur.

## 🧹 Data Preparation

Data preparation was performed using **Power Query** and Power BI.

The process included:

1. Importing recruitment data.
2. Reviewing data structure and columns.
3. Cleaning and preparing the dataset.
4. Checking candidate-level recruitment status.
5. Creating recruitment stage information.
6. Creating a **Stage Order** column to maintain the correct funnel sequence.
7. Preparing the data for KPI calculations and visualizations.
8. Creating measures using DAX.
